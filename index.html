About

I'm a Software Development Engineer in Test (SDET) at PharmEasy, one of India's leading digital healthcare companies. I test and automate the APIs behind Pharmacy, Diagnostics, Doctor Consultation and other services, and own the test strategy for the Offline Doctor Consultation partner integration.

My core is API test automation with Rest Assured (Java), Postman and cURL: 60+ RESTful APIs and microservice integrations validated, 17 automated scenarios in Rest Assured and Playwright, and 45+ defects found in a single major feature before production. I also built a Jenkins-triggered utility that cut order status changes from half a day to 5 minutes.

Beyond work, I build QA projects end to end: MediCart (an e-pharmacy test platform) and a chatbot evaluation harness for safety and hallucination checks. I started as a backend intern at LG Electronics (Java, Spring Boot, MySQL), which is why I read code and logs while testing, not just the UI.
