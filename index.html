About

I'm a Software Development Engineer in Test (SDET) at PharmEasy, one of India's leading digital healthcare companies, where I own quality for features across Pharmacy, Diagnostics (pre- and post-order processing), Plus/Pro membership and the new Offline Doctor Consultation launch.

I specialize in API test automation (Rest Assured, Postman, cURL), validating 60+ RESTful APIs and microservice integrations, and finding defects before they reach production — 60+ in a single feature alone. A Java & Spring Boot background from LG Electronics (where I built backend modules and RESTful APIs) means I can read the systems I test, not just click through them, which shapes sharper test cases and smarter automation.

My focus: catching what breaks before users do — through strong API automation, sharp test design and a real understanding of the backend underneath.
