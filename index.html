About

I'm a Java engineer with hands-on backend development experience from LG Electronics, where I built Spring Boot modules and RESTful APIs, independently led development of a microservice, and earned a Letter of Recommendation.

Today I'm a Software Development Engineer in Test at PharmEasy, one of India's leading digital healthcare companies. I work across Pharmacy, Diagnostics (pre- and post-order processing), Plus/Pro membership and the new Offline Doctor Consultation launch, validating 60+ APIs and microservice integrations and writing API automation in Rest Assured (Java).

Working this close to production has shaped how I think about backend engineering: API contracts first, failure paths always, and integrations (payments, auth, partner platforms) treated with care. Outside work I build full-stack projects like PixWipe, an AI SaaS with Spring Security, JWT and Razorpay.

My focus: building reliable, scalable backend systems with Java, Spring Boot and SQL.
